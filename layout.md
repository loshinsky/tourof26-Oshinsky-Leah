# Layout Audit

| Where             | What's being lined up                          | One direction or two? | Grid or flex? | Why                                                                           |
| ----------------- | ---------------------------------------------- | --------------------- | ------------- | ----------------------------------------------------------------------------- |
| Page              | All main website sections                      | Two                   | Grid          | Grid organizes the page into columns and rows and keeps the sections aligned. |
| Navigation        | Logo and navigation links                      | One (a row)           | Flex          | Flex keeps the logo and links in one horizontal row.                          |
| Hero              | Banner image, heading, description, and button | One (a column)        | Flex          | Flex stacks the hero content vertically and keeps everything organized.       |
| My Fridge         | Fridge, Pantry, and Leftovers                  | One (a row)           | Grid          | Grid allows the three sections to sit side by side in equal columns.          |
| Fridge section    | Section heading and ingredient items           | One (a column)        | Flex          | Flex stacks the heading and ingredient information vertically.                |
| Pantry section    | Section heading and pantry items               | One (a column)        | Flex          | Flex organizes pantry items underneath their heading.                         |
| Leftovers section | Section heading and leftover items             | One (a column)        | Flex          | Flex keeps the leftover information organized vertically.                     |
| Meal Suggestions  | Heading and suggested meals                    | One (a column)        | Flex          | Flex stacks the heading and meal suggestions.                                 |
| Meal Planning     | Meal categories and weekly planner             | Two                   | Grid          | Grid organizes the meal planner into rows and columns.                        |
| Expiring Soon     | Ingredient names and expiration dates          | One (a column)        | Flex          | Flex stacks the ingredients and their expiration information.                 |
| Footer            | About information and footer content           | One (a row)           | Flex          | Flex lines up footer content horizontally.                                    |
