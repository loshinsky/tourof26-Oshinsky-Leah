## Midterm Reflection

During this project, I learned how HTML and CSS work together to create a functional website. I became more comfortable using flexbox and grid to organize content. I also learned how important accessibility and responsive design are. One of my biggest challenges was making visual changes without disrupting the existing layout. Overall, I have become more confident editing and improving my website.
